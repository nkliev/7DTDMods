# NonReverseStacking
* **NOT TESTED IN MULTIPLAYER**
* EAC friendly

## About
* In vanilla environment, if you TakeAll from container and DepositeAll to it, item order will be reversed.
* This Modlet change inventory stacking order from Bottom-Right to Top-Left.
* So, you don't need to push sort button of container after TakeAll-DepositeAll.
